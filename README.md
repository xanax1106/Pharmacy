# 屏基藥品查詢｜介面操作預覽

本次依使用者授權，將藥品查詢網站整理供院內主管預覽操作畫面。

GitHub Pages 預覽網址：https://xanax1106.github.io/Pharmacy/

## 發布設定

GitHub 儲存庫 Settings → Pages → Deploy from a branch → main → /docs → Save。
`docs/` 為純靜態網頁，無外部程式庫、登入、資料庫或HIS連線。
原有 `AccreditationQuickRef.html` 保留，不移動或覆寫。

## 可預覽內容

- 中文／英文藥名、學名、醫令碼、院碼、健保碼及ATC查詢；途徑篩選、分頁、排序。
- 藥品照片、品項識別、既有編修內容、來源連結、收藏及列印。
- 快速查詢依英文學名A–Z；放大主要文字、縮減區塊留白。
- 八個藥品專區及換廠、缺藥、新進藥品等公告入口。正式清單與公告尚未收錄。

資料為原品項基準日的唯讀快照，1154個品項、157個編修／歷史辨識內容及49個品項照片。
網站設計日期不代表所有品項或臨床內容已重新查核。此版本供介面評估，正式上線前須經藥學部核定。
管理後台、帳號權限及伺服器儲存尚未建置；收藏僅儲存在各自瀏覽器。

## 範圍與維護

此儲存庫為公開預覽，只部署網站執行所需資產；不含原始工作簿、內部維護設定、覆核人員、編修歷程或測試資料。
網站不含病人可識別資料、密碼、API金鑰或正式資料庫連線。
後續更新請從原編修專案重新匯出公開快照，再更新 `docs/`；勿直接改公開檔取代正式主檔與覆核程序。
GitHub Pages 為公開預覽網址；搜尋引擎noindex標記不具備存取控管功能。
